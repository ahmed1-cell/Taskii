# Taskii

"Work smarter. Focus deeper. Ship faster."

Developed by **Muhammad Ahmed**

## Core Features
- **User Authentication & Workspaces**: Secure user registration and login (JWT).
- **Task Management (CRUD)**: Create, Read, Update, and Delete tasks, including nested sub-tasks.
- **Flexible Task Views**: Display tasks in a detailed List View and a draggable Kanban Board.
- **Pomodoro Timer Integration**: Track focus sessions against specific tasks.
- **Productivity Analytics**: Dashboard to visualize task completion rates.
- **Shared Workspace**: Real-time updates for collaborative projects.
- **AI-Powered Task Breakdown**: Suggest detailed sub-tasks using generative AI.

## Tech Stack
- **Frontend**: Next.js 14, React 18, TypeScript, Tailwind CSS, shadcn/ui.
- **State**: Zustand.
- **AI**: Genkit with Google AI.
- **Database**: MongoDB (via MERN Architecture).
