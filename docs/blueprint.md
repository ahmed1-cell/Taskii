# **App Name**: Taskii

## Core Features:

- User Authentication & Workspaces: Secure user registration and login (JWT), allowing users to create and manage personal task workspaces.
- Task Management (CRUD): Create, Read, Update, and Delete tasks, including nested sub-tasks, assignable priority levels, and basic recurrence (daily/weekly).
- Flexible Task Views: Display tasks in a detailed List View and a draggable Kanban Board with standard 'To-Do', 'In-Progress', and 'Done' columns.
- Pomodoro Timer Integration: An integrated Pomodoro timer allowing users to link and track focus sessions against specific tasks.
- Basic Productivity Analytics: A dashboard to visualize personal task completion rates and overview of overdue tasks using simple charts.
- Shared Workspace Real-time Updates: Ability to create shared workspaces, invite other users, and view real-time status updates for tasks within these spaces.
- AI-Powered Task Breakdown Tool: A generative AI tool that can suggest detailed sub-tasks and an initial action plan when given a high-level goal or project description.

## Style Guidelines:

- The overall scheme will be light, clean, and focused to enhance productivity and maintain a minimalist aesthetic.
- Primary color: A medium-muted blue (#4080BF) that conveys calm, reliability, and focus, suitable for prominent UI elements and calls to action.
- Background color: A very light, desaturated blue-gray (#F6F7F9) providing a neutral, spacious canvas that lightly complements the primary color.
- Accent color: A soft, cool purple (#9970C2) to draw attention to interactive elements, alerts, or key notifications, offering a gentle contrast without being jarring.
- All text will use 'Inter', a grotesque sans-serif font known for its legibility and modern, objective appearance, ideal for both headlines and body text in a productivity application.
- Emphasize a clean, line-based icon set. Icons should be clear, intuitive, and seamlessly integrate into the minimalist design, avoiding overly decorative styles.
- Employ a structured, grid-based layout with generous white space to maintain clarity and ease of navigation. Information hierarchy will be carefully considered to present tasks and data efficiently.
- Implement subtle, functional animations for user feedback, transitions between views, and drag-and-drop interactions to enhance the user experience without causing distraction.
